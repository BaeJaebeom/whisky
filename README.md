# 위스키 노트

위스키 마시고 남기는 리뷰 블로그. `main`에 올리면 1~2분 뒤 https://baejaebeom.github.io/whisky/ 에 반영됨.

## 글 쓰기

```text
content/
├── scotch/                 ← 분류 (왼쪽 메뉴)
│   ├── _index.md           ← 메뉴 이름·순서
│   └── glenfiddich-12/     ← 리뷰 하나 = 폴더 하나
│       ├── index.md        ← 글
│       ├── cover.jpg       ← 대표 사진 (없어도 됨)
│       └── glass.jpg       ← 본문 사진 (없어도 됨)
├── irish/
└── american/
```

1. 분류 폴더 안에 리뷰 폴더 만들기. 이름은 영어 소문자랑 `-`만. 이게 그대로 주소가 됨.
   예: `content/scotch/glenfiddich-15/` → `/whisky/scotch/glenfiddich-15/`
2. 그 폴더에 아래 [양식](#양식)을 `index.md`로 저장하고 채우기.
   로컬에서는 `hugo new content scotch/glenfiddich-15/index.md` 하면 양식에 오늘 날짜까지 들어간 채로 만들어짐.
3. 사진은 같은 폴더에 넣기. 대표 사진은 이름을 `cover.jpg`로, 본문 사진은 넣을 자리에 `![잔에 따른 모습](glass.jpg)`.
4. 다 썼으면 `draft: true`를 지우거나 `false`로 바꾸기. `true`면 올려도 사이트에 안 나옴.
5. 커밋하고 `main`에 push.
   GitHub 웹에서는 분류 폴더로 들어가서 **Add file → Upload files**에 리뷰 폴더를 통째로 끌어다 놓고 main에 바로 커밋하면 됨.
6. 저장소 **Actions** 탭에 초록 체크 뜨면 끝. 빨간 X면 로그에 어떤 파일이 문제인지 나옴. 이때 사이트는 직전 상태 그대로임.

- 다른 컴퓨터에서 올린 게 있으면 쓰기 전에 pull 먼저. 안 받고 push하면 거절됨.
- 저장소 화면에서 `.` 누르면 브라우저용 VS Code가 열림. 거기서 바로 쓰고 커밋해도 됨.

## 양식

```markdown
---
draft: true
title: 글렌피딕 12년
date: 2026-11-04
태그: [셰리, 버번]

카테고리: 스카치 위스키
타입: 싱글 몰트
지역: Speyside
증류소: 글렌피딕 증류소

매시빌:
증류:
캐스크:
숙성:

도수:
용량:
색소:
칠필터링:

가격:
구매처:
구매일:
---

## 노즈

## 팔레트

## 피니시
```

`카테고리`부터는 리뷰의 정보 표로 나옴. 적은 순서 그대로, 빈 줄 자리에 구분선.

### 적을 때 주의

- `date`는 꼭 적기. 없으면 빌드 실패. 미래 날짜로 적어도 바로 공개됨.
- `title`, `date`, `draft`, `태그`는 이름 바꾸면 안 됨.
- 표 항목은 맘대로 더하고 빼도 됨. `나이테: 12개` 한 줄 쓰면 표에 한 줄 생김.
- 항목 이름은 한글로. `description`, `weight`, `url` 같은 영어 이름은 Hugo가 따로 쓰는 거라 표에 안 나오고 사이트가 이상해질 수 있음.
- `캐스크`, `도수`는 목록에서 제목 밑 줄에도 나옴. 이름 바꾸면 거기서 빠짐.
- 모르는 값은 비워 두면 됨(표에 `—`로 나옴). `가격: -`처럼 `-`만 쓰면 빌드 실패.
- 값에 ` #`이나 `: `가 들어가면 큰따옴표로 감싸기. 예: `매시빌: "옥수수 (Mash Bill #1)"`
- 값은 한 줄로. 여러 개면 `향: [바닐라, 꿀]`.
- `카테고리`는 표에 나오는 글자일 뿐임. 왼쪽 메뉴 분류는 폴더로 정해짐.

### 태그

- `태그: [셰리, 버번]`처럼 대괄호로. 대괄호 빼면 빌드 실패.
- 태그 이름에 쉼표 쓰면 빌드 실패.
- `40%`랑 `40`처럼 기호만 다른 태그 두 개는 주소가 같아져서 빌드 실패. 한쪽 이름 바꾸기.
- 영어는 대소문자 구분 안 함. `Sherry`랑 `sherry`는 같은 태그.
- 태그도 검색에 걸림. 본문에 `Sherry`라고 썼어도 태그에 `셰리` 넣어 두면 "셰리"로 찾아짐.

### 본문

- `## `로 시작하면 소제목. `## 총평` 같은 거 더 만들어도 됨.
- `- 건포도`처럼 쓰면 목록.
- 문단은 빈 줄로 나누기. 줄만 바꾸면 앞 줄이랑 한 문단으로 붙음.

## 사진

- JPG, PNG, WebP만 됨. 아이폰 HEIC는 JPG로 바꿔서 올리기.
- 긴 변 2000px 정도로 줄여서 올리기(맥: 미리보기 → 도구 → 크기 조절). 원본이 저장소에 계속 쌓임.
- **위치 정보 지우고 올리기.** 사이트에 나가는 사진엔 안 남는데, 저장소가 공개라 원본은 누구나 받을 수 있음(아이폰: 공유 → 옵션 → 위치 끄기).
- 본문에 적은 사진만 나옴. 적은 이름의 파일이 폴더에 없으면 빌드 실패.

## 분류

분류 = `content/` 밑 폴더. 폴더마다 `_index.md`를 둠.

```markdown
---
title: 일본 위스키
weight: 4
---
```

- `title`은 메뉴에 나오는 이름, `weight`는 순서(작을수록 위).
- `weight`는 분류마다 다른 숫자로. 같으면 글 올릴 때마다 순서가 바뀔 수 있음.
- 중분류·소분류는 분류 폴더 안에 폴더를 하나 더 만들고 똑같이 `_index.md` 넣으면 됨. 예: `content/scotch/single-malt/`. 깊이 제한 없음.
- 공개 글이 하나도 없는 분류는 메뉴에 안 나옴.
- 글을 다른 분류로 옮기면 주소가 바뀌어서 예전 링크는 안 열림. 폴더 옮기는 건 GitHub 웹보다 로컬에서 하는 게 편함.

## 미리보기

- 저장소 폴더에서 `hugo server -D` 실행하고 http://localhost:1313/whisky/ 로 보기. 초안도 보임.
- 검색은 배포할 때 색인을 만들어서 미리보기에서는 안 됨.
- `layouts/`에 파일을 새로 만들었는데 "not found" 오류가 나면 서버 껐다 켜기.

## 사이트에서 찾기

- 왼쪽 태그 누르면 고르고, 다시 누르면 풀림. 여러 개 고르면 그 태그가 다 달린 글만 나옴.
- 검색은 단어 앞부분으로 찾음. "계피"로 "계피맛"은 찾는데, "로소"로 "올로로소"는 못 찾음.
- 분류 화면에서 찾으면 그 분류 안에서만 찾음.
- 조건이 주소에 남아서 그 주소 그대로 보내면 같은 결과가 열림.
